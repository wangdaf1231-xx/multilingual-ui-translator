# 一周最小方案：只解决两个问题

员工侧：**粘贴中文即可**；有 UI 类型时按控件约束翻，没有就按正常翻译。  
不建「本版待译」表。研发仍从现有在线翻译文档捞取，员工把结果自己贴回去即可。

只解决：

1. **同一中文不再被不同人翻成不同词** → 先查翻译记忆，命中就复用，禁止重翻。
2. **按钮/标题不再过长** → 员工若选了 UI 类型，按该类型限长；没选则不限按钮字数。

---

## 1. 员工怎么用

```text
立即登录
查看详情
```

需要按按钮/标题控长度时，再加上 UI 类型：

```text
UI类型：按钮
立即登录
查看详情
```

得到七国译文后，粘贴进你们现在那份在线翻译文档。流程到此结束。

不要让员工维护待译表、不要让员工改提示词。

---

## 2. 背后准备（做一次，员工不用碰）

已从全版本文档整理好，直接用 [翻译库.xlsx](../翻译库.xlsx)：

- **翻译记忆**：同一中文只留一行，新版本译文优先；缺的语言留空，下次用到再补。泰语已去掉。
- **术语库**：短词候选，产品先核对再当强制译法（不要直接全量当金标准）。
- **来源扫描 / 整理说明**：看各版本吃进去没有、合并规则。

上传到 AI 工具时，只传这两个 sheet 即可。新词定期追加进翻译记忆后重新上传。

新词：产品定期把「这次新翻的中文+七国」追加进翻译记忆，重新上传。不要自动全量入库。

---

## 3. 固定提示词

测试用完整版（含各 UI 类型约束、表格输出、翻译库缺语言检查）见 [固定提示词-测试用.md](固定提示词-测试用.md)。把「提示词正文」整段贴进模型系统说明即可。

---

## 4. 用什么工具做（除了公司 AI 中台）

员工入口都一样：贴中文 + 选/写 UI 类型。差别只在哪家模型、翻译记忆怎么挂上。

### 方案 A：ChatGPT / Claude / Gemini 项目（0 开发，推荐本周就用）

| 工具 | 怎么做 |
|---|---|
| [ChatGPT](https://chatgpt.com) 自定义 GPT | 上传术语库 + 翻译记忆；Instructions 贴第 3 节；Conversation starters 做成「按钮」「标题」「正文」等。员工先点 UI 类型，再贴中文 |
| [Claude](https://claude.ai) Project | 同样上传两个文件 + 系统说明。员工每条消息写「UI类型：按钮」+ 中文。长表检索通常更稳 |
| [Gemini](https://gemini.google.com) Gem | Gem 说明写死第 3 节并上传文件。员工按固定格式输入 |

公司中台 Gemini 3.1 Pro 也可以：把第 3 节做成中台里的固定应用/助手，员工只填两个字段。

限制：聊天知识库偶尔会漏检。系统说明里必须写「找不到完全一致才许新翻」。重要高频句以翻译记忆文件为准，产品抽查几次即可。

### 方案 B：DeepL

欧语质量好，有 [Glossary](https://support.deepl.com/hc/en-us/articles/4406195275666-Glossary) 管术语。  
它不能选 UI 类型。用法：DeepL 先出七国 → 按钮/标题明显过长时，再丢给方案 A 按 UI 类型压短。不适合当唯一入口。

### 方案 C：一页小表单 + 脚本（有开发，3–5 天）

页面上只有：中文输入框、UI 类型下拉、翻译按钮、七国结果（可一键复制）。

逻辑：中文在翻译记忆里完全匹配 → 直接显示；否则调公司中台，或 OpenAI / Claude / Gemini 官方 API / DeepL。新结果需产品点「写入翻译记忆」才追加。

这是以后可以长成工作台的最小雏形，本周不是必须。

---

## 5. 一周排期

| 天 | 事 |
|---|---|
| D1 | 研发导出全量七国 → 做成翻译记忆文件并去重；产品整理 50–100 条术语 |
| D2 | 建 ChatGPT GPT / Claude Project / 中台助手，上传两份文件，写入第 3 节提示词；入口做成「贴中文 + 选 UI 类型」 |
| D3–D4 | 用真实文案试：库里有的必须原样返回；按钮要短；把结果贴回现有翻译文档给研发 |
| D5 | 德/波仍长就收紧提示词；把本周新词追加进翻译记忆并重新上传 |
| D6–D7 | 再试一轮；发 10 行操作说明；冻结提示词，禁止同事私自用别的聊天窗口翻 |

交付物：两个文件 + 一个固定 AI 助手。不是新表格，不是新系统。

---

## 6. 验收

- 员工只粘贴中文并选择 UI 类型，不写提示词。
- 翻译记忆里已有的中文，七国与库内一致。
- 按钮/标题明显短于正文风格；过长要改到能用再贴进翻译文档。
- 现有在线翻译文档和研发捞取方式不变。
