# 多语言 UI 翻译助手

给海外 App 做界面本地化：中文文案一次得到英、法、德、意、波、西、葡。同一句中文只保留一套译法，避免多人各翻各的。

## 使用指南

打开 **翻译对话**，把要上线的中文贴进去，发送即可。不必写提示词、不必自己查旧表。

- **库里有的**：七国译文原样出来，和以前上过线的用词一致。
- **库里没有的**：由 LLM 新译，并标明是新译。你核对后点「确认入库」，下次所有人都会用这一套。觉得不对可以拒绝，不会进库。
- **要控长度**：左下角选 UI 类型。不选则按完整句子译，系统不会猜成按钮或标题。类型怎么约束译文，见下方「UI 类型」。
- **要表格**：同一条消息里写上 `excel`，会按本轮结果导出文件，方便贴回研发用的翻译表。
- **知识库 / 技能中心**：可以看术语和翻译记忆、导入导出 Excel；也可以换一套翻译规则（例如不同产品线）。日常翻译只用对话页就够。

原则：人只负责贴中文、选不选控件类型、以及新词要不要入库。查库和组表由系统完成。

## 工作原理

发送后按固定顺序处理：先查库，缺了再让 LLM 补译，确认后才写入。

**步骤**

1. 解析输入：中文行、可选 UI 类型、是否导出、确认 / 拒绝 / 覆盖。
2. 按当前 Skill 绑定的知识库等值检索：先术语库，再翻译记忆。
3. 七国齐全则复用，本轮禁止重翻。
4. 未命中或缺语言时，把待译项、已锁定译法、Skill 任务说明交给 LLM，只填缺的语言。
5. 返回表格 + 命中检查。新译待确认后写入翻译记忆（短词可同时进术语库）。已有条目需明确覆盖。
6. 需要时按本轮结果导出 Excel。

模型不判断某词在不在库里，也不直接改库。库中已有且七国齐全时，即使用户选了 UI 类型，也仍复用旧译文，避免同一中文两套说法。

**UI 类型**

UI 类型描述的是文案在界面上的位置，不是「翻短一点」这么简单。不选时走「正常翻译」：完整、自然，不硬截字数。选了以后，约束写在 Skill 的任务说明里，只在 **LLM 新译** 时生效。

设计要点：

- **先定英文，再套其他语言。** 同一类型下先出英文，再检查法/德/意/波/西/葡是否超长。德语、波兰语单词更长，优先短词。
- **两道上限。** 一是「英文实际字数 × 该语言扩写系数」，二是「该类型的英文上限 × 系数」。系数大约是：英 1.00，法 1.20，德 1.35，意 1.15，波 1.30，西 1.15，葡 1.15。例如按钮英≤16，则德大约 ≤22。
- **法律协议不套字数上限**，求严谨不求短。

| 类型 | 怎么译 |
|---|---|
| 按钮 | 1–3 个词，不要整句。英≤16。如「查看详情」→ Details |
| Tab / icon / 功能入口 | 名词为主，一两个词。Tab 英≤12，icon 英≤16；不要加「功能」「入口」 |
| 页面标题 / 卡片标题 | 短名词短语、单行；卡片比页面标题更短 |
| 数据标签 / 状态标签 | 指标名或可扫读状态，极短 |
| Toast / 错误提示 / 占位符 / 弹窗 | 一句说完；错误提示带下一步、不责备 |
| 说明 / 健康建议 | 面向手机屏幕说完整；健康建议不下医疗结论 |
| 法律协议 | 术语严谨，品牌名不译 |

**架构**

```text
页面（翻译对话）
    │  session + skill + kb + 中文 / 确认动作
    ▼
工作流            FastAPI /api/chat
    ├─ 解析消息
    ├─ Skill（YAML：任务说明、绑定知识库、可用能力）
    ├─ 知识库 lookup
    ├─ LLM translate（仅未命中 / 缺语言）
    └─ confirm_write / export_xlsx
```

对话页只负责展示和确认；规则在 Skill；检索与写入由工作流按顺序执行。

**Skill**

可切换的翻译规则，文件在 `skills/*.yaml`，技能中心可改，对话里选用。

| 字段 | 作用 |
|---|---|
| 任务说明 `system_prompt` | 怎么译：本地化而非逐字、JSON 输出、品牌名不译、按 UI 类型限长 |
| 知识库 `kb_ids` | 查哪本术语库 / 翻译记忆 |
| 能力 `tools` | `lookup` 查库、`translate` 新译、`confirm_write` 确认入库、`export_xlsx` 导出 |

默认技能 **多语言翻译**：海外 App 界面、七国输出；库检索由系统完成；按钮 / Tab / 标题等压字数（德、波更容易超长）；法律协议不套字数上限。
